# Sources and licenses

Delegated Work is an original synthesis for hota911's delegation workflow,
distributed under the repository MIT license. Conceptual adaptations include
dependency-aware questions and recommendations, durable execution records, and
evidence-based completion. No upstream scripts, hooks, tool dispatchers, or required
sub-skills are bundled. Retained upstream MIT notices follow for those adaptations.

Reviewed 2026-10-06:

- [mattpocock/skills](https://github.com/mattpocock/skills/tree/4588b32ecab9ecc9fc8cc6b6c5e7d675b6004b0d),
  `skills/productivity/grill-me/SKILL.md` and `grilling/SKILL.md`: dependency-aware
  interviewing and discoverable facts. Adapted to bounded preparation and delegated
  discretion rather than exhaustive interviewing. MIT.
- [obra/superpowers](https://github.com/obra/superpowers/tree/8ca22dba9a94f28898bbce59f2537ff4d87c747d),
  `skills/executing-plans/SKILL.md` and `skills/verification-before-completion/SKILL.md`:
  task records, continuous execution, and evidence before completion. Adapted for
  non-code assignments without mandatory TDD, subagents, or Git workflows. MIT.

Other skills mentioned in the conversation were not incorporated into this package.
License texts were read from the pinned repositories; attribution is retained inside
the installable skill directory, not only in the repository README.
