# 出典

この規範の根拠である。
書くときに読む必要はない。
規則の由来を確かめたいとき、規則どうしが衝突して見えるとき、規則を足すか変えるかを決めるときに読む。

## 木下是雄『理科系の作文技術』

中公新書。中央公論社、1981年9月刊。
[SKILL.md](../SKILL.md) の規則の多くはこの本に拠る。
原典の語をそのまま使っているものは、重点先行主義、概観から細部へ、一文書一主題、目標規定文、逆茂木型である。

| 節 | 内容 | 本規範での位置 |
| --- | --- | --- |
| 1.1 チャーチルのメモ | 1940年のメモを引いて、報告書を短くすること、要因の分析や統計を付録に回すことを挙げている | 読み直して削る |
| 1.2 この書物の目標 | 自分だけが読む記録と、他人に読んでもらう仕事の文書を別のものとして分ける | 本規範が扱うのは後者である |
| 2.2 文書の役割の確認 | 書く前にその文書の役割を確かめることを第一の前提とし、読者がこの文書に何を期待しているはずかを考えるよう勧めている。研究費の申請書の役割を、研究の価値と実現の見込みに対する判断の資料を提供することだとしている | 書き始める前に決めること |
| 2.3.2 一文書一主題（原典の語） | 別の主題が混ざると説得力が落ちること、目的の外で得た重要な情報は分離できる付録か別の報告にすることを挙げている | 同上 |
| 2.3.3 長さの制限 | 長さの制限が主題の選定を制約し、狭いスペースに無理に多くを書こうとしても有効な議論にならないとしている | 同上 |
| 2.3.4 読者 | 主題の選定と材料の取捨にあたっては、読者が誰で、どれだけの予備知識をもち、その文書に何を期待するかを十分に考慮しなければならないとしている。専門家には常識のことを長々と書いても読まれない例を挙げている | 同上 |
| 2.4 目標規定文（原典の語。著者の造語） | 何を主張しようとするのかを1つの文にまとめてから書き始めることを勧めている | 同上 |
| 3.1.2 重点先行主義（原典の語） | 仕事の文書はすべて重点先行主義で書くべきものとし、表題か書き出しの文を読めば最も重要なポイントが分かるように配慮すべきだとしている | 冒頭に置くもの |
| 3.2 序論、3.3 結び | 序論の役割を、読者が本論を読むべきか判断する材料を示すことと、必要な予備知識を与えることだとしている。能書きを並べず判断は読者にゆだねること、「重要な」「興味ある」という類の形容詞を混入させるべきでないことを挙げている | 同上 |
| 3.4.1 概観から細部へ（原典の語） | 冒頭の短く要を得た記述で概観がつかめると、細部の理解が格段に容易になるとしている | 同上 |
| 3.4.3 論理展開の順序 | 自分がたどった紆余曲折した道ではなく、結論から振り返って見つけた最も簡明な道に沿って書くべきだとしている。理論の基礎にある仮定が目立つように書くことも挙げている | 自分の作業経緯は書かない／確かさの書き分け |
| 3.5 文章の構成案のつくり方 | 文章の死命を制するのは構成であり、語句のえらび方や口調のよさは二の次だとしている | この規範が形式ではなく構成を扱う理由 |
| 5.1 レゲットのいうこと | 一つ一つの文は、読者がそこまでに読んだことだけで理解できるように書くこと、少々くどいと思っても論理の鎖の環をはぶかないことを、英語論文の要請として挙げている | [構成と論証を点検する](logic.md)／[日本語の文と段落](japanese-prose.md) |
| 5.2 文の構造 | 長い前置修飾節が積み上がる文（逆茂木型）の読みにくさと、避けるための3つの心得（長い前置修飾節を2つ以上書きこまない、修飾節の中のことばに修飾節をつけない、前とのつながりが分かることばで書きはじめる）を挙げている。直す手法として、長すぎる文の分割と、前置修飾節が修飾していることばを前に出すことを挙げている | [日本語の文と段落](japanese-prose.md) の「文を整える」に3つとも入れてある |
| 5.3 文章の流れ | 論文は読者に向けて書くもので著者の思いをみたすために書くものではないとし、著者が迷い歩いた跡を表に出すべきでない、序論は読者を最短径路で本論にみちびき入れるように書く、としている | 自分の作業経緯は書かない |
| 第7章 事実と意見 | 事実と意見を書きわけること、仕事の文書では事実の裏打ちのない意見の記述を避けることを、2つの心得として挙げている | 確かさの書き分け |

### 取り込まなかったもの

原典の規則のうち、意図して採らなかったものが2つある。
どちらも、原典が前提にしている場が本規範の前提と違うためである。
この違いは [SKILL.md](../SKILL.md) の冒頭に前提として書いてある。

1.1 のチャーチルのメモの (iii) は、正式の報告書ではなく見出しだけを並べたメモを用意し、必要に応じて口頭でおぎなうほうがよい場合が多い、としている。
これは口頭で補える場が毎回あることを前提にしている。
本規範は、説明の場を毎回は取れないので文書が単独で立つ必要がある、という側に立つ。

3.2 は、理科系の仕事の文書の読者には職業意識があり、読むべき文書なら読むという気構えがあるので、読む気を起こさせる技巧は無用だとしている。
本規範は、送っても読まれないことがある、という側に立つ。
ただし同じ節の「読者が本論を読むべきか判断する材料を示す」は採っている。

## 鹿野桂一郎氏の gist

[日本語の文と段落](japanese-prose.md) は、鹿野桂一郎（[k16shikano](https://gist.github.com/k16shikano/fd287c3133457c4fd8f5601d34aa817d) /[@golden_lucky](https://x.com/golden_lucky)）氏が公開した gist を元にした派生物である。
原著者は gist の改変・再配布を公に歓迎している（[出典スレッド](https://x.com/f4ah6o/status/2067215523067400244)）。

元の規範は書籍の原稿を想定していた。
書籍に固有の規則（場面の山場、伏線とその回収、章をまたぐ前方参照、結論を見出しで明かさない演出）は、共有文書では害になるので落としてある。
とくに最後のものは重点先行主義と衝突する。
仕事の文書は、結論を見出しと冒頭で明かすのが正しい。

[構成と論証を点検する](logic.md) の点検項目と「読者の負荷を減らす」も、この gist に由来する。
言語に依らない規則なので、日本語のファイルから分けた。

## 出典のない規則

次は、作者の経験にもとづく。
検証していない。
外れている可能性があり、この規範を改訂するときに最初に疑う対象である。

| --- | --- |
| 文書が完成して見えると、読者は指摘する箇所を見つけにくい | 作者が立てた仮説。この規範はこれが当たっている前提で書いてある。検証していない |

| 同じ論点について指摘と承認を同時に求めると、読者はどちらを返せばよいか決めにくい | 経験則 |
